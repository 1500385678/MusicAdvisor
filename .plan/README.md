# MusicAdvisor · 每日开发计划目录

> 19-音乐-Music · `.plan/` 目录说明
>
> **作用**:为每日 T4(02:00 优化)与 T5(03:00 推 release) 阶段提供当日/次日的开发计划落库位置。
>
> **创建**:2026-08-26(T1 巡检建议 P2 落地)

---

## 命名规范

- **次日计划文件**:`.plan/YYYYMMDD.md`(由 T4 02:00 写入,描述次日 T5 03:00 应执行的 1 个小变更)
- **当日占位**:`.plan/YYYYMMDD.md`(可由 T1 03:00 创建空文件占位,待 T4 当晚补内容)
- **特殊标记**:`.plan/.tmp-*`(临时实验,T5 完成后清理)

## 文件约定

- 每个 `.plan/YYYYMMDD.md` 必须包含 3 段:
  1. **目标** — 1 句话,1 个最小可入库的产出
  2. **变更** — 文件路径 + 章节 + 改写/新建(简洁可入库)
  3. **关联** — 勾选 `项目开发计划.md` 中的哪个 checkbox

## 生命周期

| 阶段 | 动作 |
|------|------|
| T4 02:00 | 写 `.plan/次日.md`(描述次日 T5 应做) |
| T5 03:00 | 读 `.plan/当日.md` → 实际产出 → git add + push |
| T5 03:00 后 | 删 `.plan/当日.md`(除非需要长期保留) |
| 巡检 | 02:00 巡检项检查 `.plan/` 是否有昨日未清理文件 |

## 与其他目录的关系

- **`.Log/`** — 巡检日志(02:00 落,只增不删)
- **`.plan/`** — 开发计划(02:00 写,03:00 读后清理)
- **`InspirationIndex.md`** — 资产盘点索引(T5 增量更新)
- **`项目开发计划.md`** — 阶段计划主源(checkbox 由 T5 勾掉)
